# Faber-Castell · Catálogo (protótipo)

Site com catálogo, carrinho e pedido pelo WhatsApp. HTML, CSS e JavaScript puros, sem build.

## O que trocar
- `script.js`: número do WhatsApp (`WHATSAPP`) e a lista `PRODUTOS` (nome, descrição, preço, categoria).
- `index.html`: endereço, horário, formas de pagamento, link do Instagram e mapa.
- Produtos usam ilustrações em SVG. Para usar fotos, troque a função `arte()` no `script.js`.

## Publicar
Na Vercel: Add New > Project, importe este repositório e clique em Deploy. O Root Directory fica `./` (não mude nada).
